## TaskManager(Gerenciador de Tarefas)

Gerencia suas tarefas do dia a dia, colocando suas tarefas que são prioridade em primeiro lugar.

# Funcionalidades

- Adicionar

- Editar

- Remover

- Concluir

---
# Mais Informações

- Tarefas prioritarias não selecionadas tem uma cor bege, quando selecionada suas letras ficam brancas para diferenciar das tarefas normais(tarefas não prioritarias)
